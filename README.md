# 🚀 Programming Practice Repository

Welcome to my **Programming Practice Repository**!

This repository is a centralized collection of my programming practice, coding exercises, hands-on experiments, notes, and projects. I use this repository to strengthen my programming fundamentals, improve problem-solving skills, and continuously explore new technologies.

My goal is to maintain a structured record of my learning journey, from basic programming concepts to advanced development techniques.

## 📚 Technologies & Topics Covered

This repository contains practice files and code examples related to the following technologies:

### 🌐 Frontend Development
- **HTML5** – Web page structure, forms, semantic elements, and accessibility.
- **CSS3** – Styling, layouts, Flexbox, Grid, animations, and responsive design.
- **JavaScript** – Variables, functions, arrays, objects, DOM manipulation, events, promises, async/await, and ES6+.
- **React.js** – Components, props, state, hooks, event handling, routing, and component-based architecture.

### ⚙️ Backend Development
- **Java** – Core Java, OOP concepts, collections, exception handling, multithreading, and more.
- **Python** – Fundamentals, functions, data structures, OOP, modules, and problem-solving.
- **Node.js** – Server-side JavaScript, modules, APIs, and asynchronous programming.
- **Express.js** – Routing, middleware, REST APIs, and server-side development.

### 🗄️ Database Management
- **SQL** – Queries, joins, subqueries, constraints, functions, DDL, DML, and database operations.
- **MongoDB** – CRUD operations, collections, documents, aggregation, and database management.

### 🧠 Data Structures & Algorithms (DSA)

- Searching Algorithms

- Recursion and Backtracking
- Trees and Binary Trees

### 🛠️ Other Tools & Technologies
